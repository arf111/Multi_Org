# CLIP-Driven Universal Model

This project implements a **CLIP-driven universal model** for vision-language tasks, adapted from the [original repository](https://github.com/ljwztc/CLIP-Driven-Universal-Model).  We have tried to experiment with bunch of different prompts to see the effects on the model. We have used the pretrained clip model and used it to embed the text, for image encoder we have used their architecture as well
- [CLIP-Driven-Universal-Model](https://github.com/ljwztc/CLIP-Driven-Universal-Model)
